# HandyBot — gesture chatbot for Discord

A Discord bot that answers messages with hand-gesture emoji. It doesn't use keyword matching: a small neural network classifies the *intent* of each message and picks a fitting gesture.

## Examples

| You write | HandyBot answers |
|---|---|
| hello / hey / what's up? | 👋 or 🖖 |
| good, cool | 👍 |
| luck | 🤞 |
| peace | ✌️ |
| OK, fine | 👌 |
| tiny, small | 🤏 |
| stop it, enough | 🤚 |
| scary, AAAAAAAAAAA | 🖐️ |

There are 24 intents in total, all described in [`intents.json`](intents.json).

## How it works

```
message ─▶ tokenize ─▶ drop stop words ─▶ normalize words ─▶ bag of words ─▶ neural net ─▶ gesture
```

1. **Tokenize.** The message is split into words with NLTK.
2. **Drop stop words.** Common words ("the", "and", "и", "но") are removed using combined English and Russian stop-word lists.
3. **Normalize.** The language of each word is detected with `langid`. English words are stemmed and lemmatized with NLTK; Russian words are reduced to their base form with `pymorphy2`.
4. **Bag of words.** The message becomes a vector of 0s and 1s: one position per word in the vocabulary.
5. **Classify.** A feed-forward network (Dense 128 → Dropout → Dense 64 → Dropout → Softmax) predicts the intent. If the confidence is above 0.25, the bot replies with a random response from that intent.

The text pipeline supports both English and Russian; the current training phrases are in English.

## Commands

| Command | What it does |
|---|---|
| `/bang` | Slash command: sends a random combo of 2–4 gestures |
| `/sync` | Owner-only: re-syncs slash commands with Discord |

Messages the bot couldn't answer are appended to `logs.txt`, which is handy for finding phrases worth adding to the intents.

## Tech stack

Python · TensorFlow / Keras · NLTK · pymorphy2 · langid · discord.py


## Getting started

### 1. Install dependencies

Use Python 3.10: `pymorphy2` does not work on Python 3.11 and newer.

```bash
git clone https://github.com/Palmson/AI-gestures-chatbot.git
cd AI-gestures-chatbot
pip install discord.py tensorflow nltk pymorphy2 langid stop-words numpy
```

Download the NLTK data:

```bash
python -c "import nltk; [nltk.download(p) for p in ['punkt', 'punkt_tab', 'wordnet', 'stopwords']]"
```

### 2. Create a Discord bot

1. Open the [Discord Developer Portal](https://discord.com/developers/applications) and create an application.
2. On the **Bot** page, copy the token and turn on all three **Privileged Gateway Intents** (Presence, Server Members, Message Content). The bot requests all intents and won't start without them.
3. Invite the bot to your server with the `bot` and `applications.commands` scopes.

### 3. Configure `bot.py`

Replace the placeholders in `run_discord_bot()`:

```python
token = 'your-bot-token'
my_guild = discord.Object(id=123456789012345678)  # your server ID (a number, no quotes)
papa_id = 123456789012345678                      # your user ID (a number, no quotes)
```

To copy IDs in Discord, enable *Developer Mode* in settings, then right-click a server or user and choose *Copy ID*.

### 4. Run

```bash
python main.py
```

## Adding new gestures

1. Add a new intent to `intents.json` with a `tag`, some `patterns` (example phrases) and `responses` (emoji codes).
2. Retrain the model: `python train.py`. This regenerates `chatbot_model.h5`, `words.pkl` and `classes.pkl`.
3. Restart the bot.
